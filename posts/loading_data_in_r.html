Getting Started

First, let’s load the packages we’ll need:

# Load packages
library(readxl)      # For reading Excel files
library(tidyverse)   # For data manipulation

Note: If you haven’t installed these packages yet, run this once in your R console:

install.packages(c("readxl", "tidyverse"))

Loading Excel Files with readxl

The readxl package is the gold standard for reading Excel files in R. It’s part of the tidyverse ecosystem and works with both .xls and .xlsx files.

Basic Usage

# Load a single sheet from an Excel file
data <- read_excel("path/to/your/file.xlsx")

# By default, it reads the first sheet

Loading Excel Files from a URL

Let’s load an Excel file directly from the web:

library(readxl)

# URL for the Excel file
url <- "https://raw.githubusercontent.com/teamarnab/Advanced-Excel/main/Advance%20Excel%20Practice.xlsx"

# Create a temporary file
temp_file <- tempfile(fileext = ".xlsx")

# Download the workbook
download.file(url, destfile = temp_file, mode = "wb")

Exploring Sheets with excel_sheets()

Before you import data, it’s often useful to know what sheets are in your workbook:

# List all sheet names in the workbook
sheets <- excel_sheets(temp_file)

Loading CSV Files Directly from URLs

Quick Reference

Task Function
List sheets (Excel) excel_sheets("file.xlsx")
Read Excel sheet read_excel("file.xlsx", sheet = "Sheet2")
Read all sheets map(excel_sheets("file.xlsx"), ~ read_excel("file.xlsx", sheet = .x))
Read CSV from URL read_csv("https://...")
